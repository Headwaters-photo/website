# Website support policy

The Headwaters marketing website targets WCAG 2.2 Level AA and supports the
current stable releases of desktop Chrome, Safari, Firefox, and Edge, plus
current iOS Safari and Android Chrome.

Release checks use Chromium, Firefox, and WebKit automation as practical engine
proxies. Representative viewport widths are 320, 375, 768, and 1440 px. The
automated proxies do not replace final checks on physical iOS and Android
devices or guarantee parity with every vendor-specific browser behavior; any
part of the matrix not exercised for a release must be recorded as unverified
in its acceptance artifact.
